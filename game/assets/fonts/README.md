# Fontlar

- `Sora[wght].ttf` — Sora değişken font (200–800), SIL OFL 1.1 (`OFL-Sora.txt`). Kaynak: github.com/google/fonts/ofl/sora. Oyuna gömmek ve web'de servis etmek serbest.
- `sora_display.tres` — **yalnızca** wordmark ve geri sayım rakamları: wght 800 + 3° sağa eğim (ITC Eras / France 98 duruşu). Başlık ve sayaçlar düz (karar 2026-10-05).
- `sora_body.tres` — gövde/buton/liste: wght 500, düz.

Eğim yönü ters çıkarsa `variation_transform` içindeki 0.0524'ü -0.0524 yap. Karar: 2026-10-05, Eras ITC lisans masrafı yerine Sora seçildi.
