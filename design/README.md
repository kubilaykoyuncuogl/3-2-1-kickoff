# Kickoff tasarım kiti

Önce KIT.html ile görsel panoyu açın. Kodlama agentı AGENT-BRIEF.md dosyasından başlasın.

Paket: açık/koyu renk tokenları, Sora yazı ölçeği, boşluk ve ölçüler, bileşen/durum sözleşmeleri, dört kullanıcı seçimi, birleşik görsel referans, kaynak ekran envanteri ve kontrast raporu.

JSON değer kaynağıdır; TypeScript dosyası üretilmiş aynadır. KIT.html hızlı inceleme içindir; sistem fontu kullanır, Sora dosyaları paketlenmemiştir. Görsel referanslar üretim assetleri veya native test kanıtı değildir.

AI slop kaynak incelemesi sonrası sadeleştirme: SLOP-REVIEW.md. Bileşen kütüphanesi 5 aile / 15 örnek içerir. Tarayıcı görüntüsü bu turda doğrulanamadı; HTML kaynak kontrolleri ve 60 kontrast çifti geçti.
